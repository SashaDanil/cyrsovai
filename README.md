
# 🍕 Система доставки еды

Веб-приложение для заказа еды с доставкой, администрированием и отслеживанием заказов в реальном времени.


## 🚀 Возможности

### Для клиентов:
- ✅ Регистрация и авторизация
- ✅ Просмотр каталога товаров
- ✅ Добавление товаров в корзину
- ✅ Оформление заказов
- ✅ Просмотр истории заказов
- ✅ **Отслеживание статуса заказа в реальном времени**
- ✅ **Поэтапное обновление статуса заказа** (pending → in_progress → delivered)
- ✅ Автоматическое назначение курьера при первом обновлении статуса
- ✅ Просмотр информации о курьере (имя, транспорт, рейтинг, телефон)

### Для администратора:
- ✅ Панель управления с общей статистикой
- ✅ Управление заказами (изменение статуса, назначение курьера)
- ✅ CRUD операции с товарами
- ✅ CRUD операции с курьерами
- ✅ Просмотр всех клиентов
- ✅ Отслеживание выручки

### Дополнительные функции:
- 🔄 Автообновление страницы отслеживания (каждые 10 секунд)
- 📊 Статус-бары для визуализации этапов доставки
- 💰 Бонусная система для клиентов
- 🏷️ Категории клиентов (обычный, постоянный, VIP)

## 🛠️ Технологии

- **Backend**: Flask (Python)
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Jinja2 templates
- **Authentication**: Сессии Flask, хеширование паролей (SHA-256)

## 📦 Установка и запуск

### Требования:
- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Инструкция по установке:

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-repo/delivery-service.git
cd delivery-service
```

2. **Установите зависимости:**
```bash
pip install flask
```

3. **Создайте базу данных:**
```bash
python create_db.py
```
Или база данных создастся автоматически при первом запуске `app.py`

4. **Запустите приложение:**
```bash
python app.py
```

5. **Откройте браузер и перейдите по адресу:**
```
http://localhost:5000
```

## 💻 Использование

### Для клиентов:

1. **Регистрация:**
   - Перейдите на `/register`
   - Заполните форму (имя, фамилия, телефон, email, адрес, логин, пароль)

2. **Авторизация:**
   - Перейдите на `/login`
   - Введите логин и пароль

3. **Просмотр товаров:**
   - На главной странице отображаются все доступные товары
   - У каждого товара указана цена, вес и описание

4. **Добавление в корзину:**
   - Выберите количество товара
   - Нажмите "🛒 В корзину"

5. **Оформление заказа:**
   - Перейдите в корзину (`/cart`)
   - Выберите способ оплаты
   - Нажмите "Оформить заказ"

6. **Отслеживание заказа:**
   - Перейдите в "Мои заказы"
   - Нажмите "📍 Отследить" у нужного заказа
   - На странице отслеживания:
     - Отображаются этапы доставки
     - Показывается информация о курьере (после назначения)
     - Кнопка "Отправить в доставку" (для статуса pending)
     - Кнопка "Подтвердить доставку" (для статуса in_progress)
     - Страница автоматически обновляется каждые 10 секунд

### Для администратора:

1. **Вход в админ-панель:**
   - Логин: `admin`
   - Пароль: `admin123`
   - После входа автоматический редирект на `/admin`

2. **Управление заказами:**
   - Просмотр всех заказов
   - Изменение статуса (pending, in_progress, delivered, cancelled)
   - Назначение курьера на заказ
   - Обновление заказа вручную

3. **Управление товарами:**
   - Добавление новых товаров
   - Редактирование существующих (название, цена, количество)
   - Удаление товаров

4. **Управление курьерами:**
   - Добавление новых курьеров
   - Редактирование статуса (active, busy, offline)
   - Изменение занятости
   - Удаление курьеров

5. **Статистика:**
   - Общее количество заказов
   - Количество клиентов
   - Количество курьеров
   - Общая выручка

## 🎯 Функционал отслеживания заказов

### Поэтапное обновление статуса:
1. **pending** (ожидает) → клиент нажимает "Отправить в доставку"
   - Назначается случайный свободный курьер
   - Статус меняется на `in_progress`

2. **in_progress** (в пути) → клиент нажимает "Подтвердить доставку"
   - Курьер остаётся тот же
   - Записывается дата доставки
   - Статус меняется на `delivered`

3. **delivered** (доставлен)
   - Кнопки управления исчезают
   - Появляется кнопка "Назад к заказам"
   - Отображается сообщение об успешной доставке

4. **cancelled** (отменён)
   - Отображается сообщение об отмене
   - Кнопка "Назад к заказам"

### Особенности:
- ✅ Курьер назначается **только один раз** при первом обновлении
- ✅ При последующих обновлениях курьер **не меняется**
- ✅ Кнопка "Обновить страницу" доступна всегда
- ✅ Автообновление работает только для активных заказов
- ✅ Визуальная индикация этапов доставки
